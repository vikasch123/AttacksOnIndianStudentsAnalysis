# AttacksOnIndianStudentsAnalysis
# Analysis of Attacks on Indian Students Abroad (2022–2024)

This project analyzes data on attacks on Indian students abroad from 2022 to 2024, using data from data.gov.in. It includes data cleaning, analysis, and visualizations to identify trends and high-risk countries.

## Files
- `analysis_notebook.ipynb`: Jupyter notebook with the full analysis and visualizations.
- `RS_Session_265_AS_190_A_and_B.csv`: Original dataset.
- `analyzed_attacks_on_indian_students.csv`: Processed dataset with calculated columns.
- `attacks_trend_line_chart.png`: Line chart showing trends over time.
- `total_attacks_bar_chart.png`: Bar chart comparing total attacks by country.

## Key Findings
- Total attacks peaked in 2023 (28 attacks) and decreased in 2024 (19 attacks).
- Russia (13 attacks) and the United Kingdom (12 attacks) are the highest-risk countries.
